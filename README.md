# TXT-to-CSV-convertor

Background: This was a fun little project I did for my Finance Derivatives class. The project entailed constructing a hedging strategy for a company wanting to lock in revenue for a commodity (corn) that it had obligated (selling) contracts to fulfill in the future. 

We received a folder with TXT files for the possible futures contracts we could trade. It was tedious to convert the files individually, so I created this R code to do it in mass and save it in a new folder.

The code is pretty simple and small, but concise and easy to use. You could also change this code to be any type of file convertor with just a few changes.
